# Prins Kumar - Personal Portfolio

A professional personal portfolio website for Prins Kumar, a BCA 3rd-year student and aspiring software/web developer.

## 🚀 About the Project

This portfolio showcases my:

- Skills
- Projects
- Education

- Spring Boot
- Gradle
